# 4MOVE iOS — код и файлы

Нативное iOS-приложение (SwiftUI, iOS 16+), **только код и правка файлов**.
Медиа, звонок и голос убраны из интерфейса. Модель и файлы живут на локальном ПК; iPhone — тонкий клиент.

## Что внутри

- **Вкладка «КОД»** — чат с локальной моделью Ollama по Wi‑Fi + команды файлов/проекта/сборки через мост.
- **Вкладка «ФАЙЛЫ»** — навигация по папкам ПК, просмотр, редактирование, создание файлов.
- Настройки — адрес Ollama, адрес и токен моста, модель, режим владельца.
- Splash с логотипом 4MOVE и версией `v.2.31.7`.
- Размер `.ipa`: ориентировочно **5–15 МБ** (модель ~2 ГБ остаётся на ПК).

## Архитектура

```
iPhone (SwiftUI)
  ├── Ollama  http://<ПК>:11435   → чат
  └── Bridge  http://<ПК>:11436   → файлы, проект, команды
        └── Assistant.exe (Windows)
              ├── токен из AppData\bridge-token.txt
              ├── whitelist путей: W:\AI-Assistant, W:\AI-Assistant-iOS, профиль
              ├── подтверждение на запись/команду
              └── аудит: AppData\security-audit.log
```

## Сборка .ipa

Есть два пути: **облачная сборка без Mac** — см. `BUILD-CLOUD.md` (рекомендую), либо свой Mac:

На Mac с Xcode 15+:

1. Открой `AIAssistant.xcodeproj`.
2. Target `4MOVE` → Signing & Capabilities → выбери свой Team (Personal Team подходит).
3. Destination — «Any iOS Device (arm64)».
4. `Product → Archive` → `Distribute App` → Development/Ad Hoc → экспорт `.ipa`.
5. Установи через Xcode Devices, AltStore, Sideloadly или TestFlight.

Без Mac и Apple ID `.ipa` собрать нельзя — это требование Apple, обход не поддерживается.

## Подготовка ПК

### 1. Ollama в LAN

Обычный `start.vbs` поднимает Ollama на `127.0.0.1:11435` — это только локальный ПК.
Чтобы iPhone видел модель, запусти Ollama так:

```powershell
$env:OLLAMA_HOST='0.0.0.0:11435'
$env:OLLAMA_MODELS='W:\AI-Assistant\Ollama-models'
& 'W:\AI-Assistant\Programs\Ollama\ollama.exe' serve
```

### 2. Мост файлов

Мост стартует автоматически вместе с `Assistant.exe` (порт `11436`).
Токен: `W:\AI-Assistant\AppData\bridge-token.txt`.

Разреши порт в файрволе Windows:

```powershell
New-NetFirewallRule -DisplayName "4MOVE Bridge 11436" -Direction Inbound -Protocol TCP -LocalPort 11436 -Action Allow -Profile Private
```

### 3. Настройка iPhone

В `4MOVE → Настройки`:

- **Локальная модель**: `http://<IP-ПК>:11435`, модель `qwen2.5:3b`.
- **Мост файлов**: `http://<IP-ПК>:11436`, токен из `bridge-token.txt`.

IP ПК узнай: `ipconfig` → «IPv4-адрес» (обычно `192.168.1.x`).

## Команды в чате

```
файл список W:\AI-Assistant
файл прочитай W:\AI-Assistant\app\Assistant.cs
файл найди W:\AI-Assistant\app обновление
файл запиши W:\AI-Assistant\app\test.txt | текст
проект W:\AI-Assistant
команда git status
/help
```

Запись и команды требуют подтверждения на iPhone и попадают в `security-audit.log`.
Перед записью мост автоматически делает `.bak`-копию.

## Безопасность

- Токен моста обязателен для любого запроса.
- Запись и shell — только с `confirmed=true` и подтверждением в UI.
- Пути ограничены whitelist; `.env`, ключи и секреты заблокированы.
- Владелец подтверждается Face ID / паролем; остальные — ограниченный режим.
- Сценарий и скрытые команды из `/help` исключены.
- **IP-адрес не пишется в аудит** — только действие и путь/команда.
- **Модель не привязывает запросы к IP**: Ollama работает локально, iPhone выходит по LAN-адресу `192.168.x.x`, внешний IP сервису не передаётся. Ротация IP не требуется и только разорвёт соединение.

## Игры (важно)

Поддерживаются только **оффлайн-одиночные игры** и оффлайн-режим гибридных игр:
локальные сохранения, конфиги, моды, резервные копии.

**Не поддерживаются**: онлайн-игры, мультиплеер, античиты, облачная синхронизация, обход защиты.
Модель получила соответствующее ограничение в скрытом сценарии.

## Известные ограничения

- Сборка `.ipa` невозможна на Windows — нужен Mac.
- Мост слушает `0.0.0.0:11436`; не открывай порт в публичной сети.
- Старые файлы Voice/Call/Media/Chat вынесены в `Legacy/` и не входят в Xcode-таргет.
